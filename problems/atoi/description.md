Read a string of ASCII digits and output the integer it denotes.

Each input is a string: a count `n`, then `n` bytes — the decimal
[ASCII](/grading#ascii) codes of the digits of a non-negative number. Output that number as an integer: the
bytes for `123` become the integer `123`.

A test case contains multiple [rounds](/grading#round-based), each carrying one
string. You won't receive the next string until you've output the current
answer.
