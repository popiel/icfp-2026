Read a list of integers and print the same list sorted into ascending order.

Each input is a list: a count `n`, then `n` integers. Print the `n` values in
ascending order. Duplicates are kept.

A test case contains multiple [rounds](/grading#round-based), each of which
contains a single list. Lists may vary in length between rounds. You won't
receive the next list until you finish printing the current one.
