This problem has no input. Your program must output an
[ASCII](/grading#ascii) string documenting the history of ICFP. For each year since 1996, output the location
of the conference and the winner of the Most Influential Paper (if named).

The first few characters of the output look like this:

`1996: Philadelphia, PA, USA "Optimality and inefficiency: ...`

[icfp-history.txt](/icfp-history.txt) contains the full text that you need to
output.

**This problem is [footprint-scored](/grading#program-scoring).** Your
score is determined solely by the size of your program (smaller is better). A
slow small program is better than a large fast one.
